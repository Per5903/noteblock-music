# NoteBlock Music

Fabric-мод для **Minecraft 26.2**: загружаешь музыку — получаешь схематику с нотными блоками, которая её играет.

> Статус: **MVP (этап 1)** — MIDI → аранжировка → `.schem` / постройка прямо в мире.
> Распознавание MP3/WAV/OGG, GUI и предпрослушивание — в планах (см. ниже).

## Как пользоваться

1. Положи `.mid` в папку `.minecraft/nbmusic/input/` (создаётся при первом запуске).
2. В игре (нужны права оператора / читы):

| Команда | Что делает |
|---|---|
| `/nbmusic list` | список файлов во `input/` |
| `/nbmusic info <файл> [скорость%] [полифония]` | статистика: длительность, сколько нот влезло, размер схемы |
| `/nbmusic export <файл> [скорость%] [полифония]` | пишет `nbmusic/output/<имя>.schem` (и в `config/worldedit/schematics`, если есть WorldEdit) |
| `/nbmusic build <файл> [скорость%] [полифония]` | строит схему в мире в 2 блоках по +X от игрока |

- **скорость%** — 100 = исходный темп, 50 = вдвое медленнее (помогает быстрым мелодиям: шаг редстоуна всего 0,1 с).
- **полифония** — сколько нот максимум звучит одновременно (1–18, по умолчанию 8). Лишние отбрасываются, начиная с самых тихих.

Запуск — кнопка на краю схемы, координаты пишутся в чат.

## Как устроена схема

```
вид сверху, одна дорожка:          слои:
                                    y=3 воздух над нотными блоками
        N     N                     y=2 механизм
B  D  R C  R  R C ...               y=1 блоки инструментов и опоры
        N     N                     y=0 опора под песком (малый барабан)

B — кнопка   D — шина из пыли (поперёк дорожек)
R — повторитель (1–4 тика)   C — носитель   N — нотный блок
```

- Повторители набирают паузу между нотами, носитель активирует два нотных блока по бокам.
- Аккорд из K нот раскладывается на ⌈K/2⌉ параллельных дорожек; все стартуют от общей шины синхронно.
- Инструмент выбирается по программе General MIDI (фортепиано → harp, бас → bass, гитары → guitar…), ударные канала 10 → basedrum/snare/hat.
  Если нота не попадает в 2-октавный диапазон инструмента, берётся запасной инструмент семейства, иначе — перенос на октаву.

## Сборка

Нужна Java 25.

```bash
./gradlew build         # jar в build/libs + юнит-тесты
./gradlew runGameTest   # headless-сервер: ставит схему, жмёт кнопку, сверяет тайминг каждой ноты
./gradlew runClient     # запустить игру с модом
```

## Структура

```
dev.nbmusic.core        чистая Java, без Minecraft (тестируется JUnit)
  ├─ io/                MidiDecoder (с картой темпов)
  ├─ arrange/           Arranger (квантизация, диапазоны, полифония), InstrumentMapper
  ├─ layout/            LayoutGenerator → BlockGrid
  └─ export/            SpongeSchematicWriter (.schem v3)
dev.nbmusic.command     /nbmusic
dev.nbmusic.world       SchematicPlacer — постройка в мире
src/gametest            GameTest с настоящим редстоуном
```
